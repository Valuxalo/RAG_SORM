# RAG по приказам СОРМ

## Введение

**СОРМ** (Система технических средств для обеспечения функций оперативно-разыскных мероприятий) — это комплекс технических устройств и программ, который операторы связи и интернет-провайдеры обязаны устанавливать в своих сетях.

**Зачем он нужен?**

СОРM нужен уполномоченным государственным органам (в первую очередь ФСБ) для контроля, перехвата и хранения информации о пользователях и их действиях в сетях связи.

**Из чего состоит система?**

• СОРМ-1: для прослушивания телефонных звонков.
• СОРМ-2: для перехвата интернет-трафика и соединений.
• СОРМ-3: для хранения данных обо всех действиях абонентов, статистики и сообщений в базах данных (до 3 лет).

Техническая составляющая СОРМ реализована на основе приказов Минкомсвязт (Минцифры России), где описано взаимодействие СОРМ и пультов ФСБ. Именно на основе этиъ приказов будет составлена БД для RAG.
